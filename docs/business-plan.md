# The Party Porch — Business Plan

## Brand
- **Name:** The Party Porch
- **Domain:** yourpartyporch.com
- **Handles:** @yourpartyporch (Instagram, TikTok, Facebook, YouTube — all secured)
- **Positioning:** Broad, product-agnostic party & event rental brand. Nerf war parties are
  the *launch product line*, not the identity — so the brand scales to photo booths, snack
  machines, backdrops, soft play, 360 booths, and more.

## Goal
Start with **Nerf war parties for kids** (mobile drop-off / setup / pickup) on a **$600
budget**. Scale to **+$10,000/month net profit within 18 months** (public launch Sept 2026
→ target hit by ~March 2028), adding rental product lines and hiring help. No chairs/tables.

> ⚠️ **Trademark discipline:** "Nerf" is a Hasbro trademark. Never in the brand name, domain,
> or handles (you're safe as "The Party Porch"). Use "Nerf" ONLY in marketing/SEO copy as
> description — *"Nerf war birthday parties"*, *"Nerf-compatible blasters"* — because that's
> what parents search.

## Unit Economics

**Core product:** mobile Nerf war party (up to 12 kids, ~2 hr). All gear included.
**Houston strategy:** a **3-tier service ladder** that undercuts every rival at every level
— families pay only for what they want (DIY drop-off → fully hosted). Competitors
(Yard Wars $245/$395, Texas Premier $325/$390, Have Several Seats $300/$500, Battlefield
Houston $349, Epik Fun) mostly sell one pricey package. Penetration pricing now → step each
tier up ~$20–40 in 2027 as reviews build.

| Tier | What we do | Price |
|------|-----------|-------|
| 1 · Drop & Go | We deliver + pick up; you set up & run | $119 |
| 2 · We Set Up | We deliver, build + tear down/pick up; you run games | $169 |
| 3 · Full Service | We deliver, set up, host runs games + safety, clean up | $219 |
| Modifier: self-pickup | −$25 any tier |  |
| Add-on: extra 5 players | +$25 |  |
| Add-on: extra hour | +$40 |  |
| Add-on: Glow/Night battle | +$79 |  |
| Add-on: The Booth | +$99 |  |
| Add-on: The Backdrop | +$79 |  |
| Add-on: The Snack Bar (per machine) | +$69 |  |
| Delivery beyond 15 mi | $2/mi |  |

- **Launch blended avg ticket:** ~$200 → ~$320 with add-ons/bundles
- **Variable cost/party:** ~$30 (Drop & Go) to ~$90 (Full Service) — gas, dart wear, labor
- **Net profit/party:** ~$90 (DIY) to ~$130 (Full Service), higher with add-ons

### Path to $10k/month NET
- ~**50 parties/month** at ~$200 net blended, OR fewer as add-on attach + the 2027 price
  step-up raise the average ticket. Reality is a mix.
- The **Drop & Go** tier has near-zero labor, so it's the volume engine that makes ~50/mo
  realistic across 2–3 kits + crews (not solo).
- Weekday revenue (schools, camps, church/community, corporate) fills the gap.
- **Biggest lever:** cheap flexible tiers win reviews + volume early, then add-ons/bundles +
  the price step-up lift net/party without losing bookings.

## The 18-Month Ramp (see launch-timeline.md for the pre-launch detail)

### Phase 0 — Launch (Sept 2026) — Budget: $600
1 Nerf kit, brand live, first paid parties. Exit: 3 completed parties, 5+ content pieces,
5-star reviews.

### Phase 1 — Validate (Oct–Dec 2026) — ~$1–3k/mo
4–8 Nerf parties/mo solo. Pull ONE popcorn machine forward. Booking system, LLC, insurance.
Milestone: 6+ bookings/mo, $500+ saved for Kit #2.

### Phase 2 — Add-ons + First Hire (Jan–May 2027) — ~$3–6k/mo
Kit #2. Launch The Booth, The Backdrop, cotton candy. First part-time helper. Weekday
channels. Milestone: 15+ parties/mo, avg ticket $380+, 1 reliable helper.

### Phase 3 — Multiply Crews (Jun–Oct 2027) — ~$6–8k/mo
Kit #3, 2 crews. Snow cone/slushie, Tiny Porch, 360 booth (adult market). Party Pack bundle.
Corporate/community events. Milestone: 25+ parties/mo, 2 semi-independent crews.

### Phase 4 — Hit +$10k/mo & Systemize (Nov 2027–Mar 2028) — Net $10k+/mo
34+ parties/mo across 2–3 crews + weekday events. Glow Zone, movie nights. Promote crew
chief. Ultimate bundles. Preferred-vendor deals. **Milestone: $10k+/mo net, hands-off on-site.**

## Risk / Watch-outs
- **Trademark:** "Nerf" only in descriptive copy, never the brand.
- **Insurance:** event liability coverage before public/large events.
- **Safety:** eye protection mandatory, age rules, signed waiver on booking.
- **Seasonality:** winters slower → indoor venues, holiday/school-break camps.
- **Burnout:** hire BEFORE maxing out weekends (Phase 2).
